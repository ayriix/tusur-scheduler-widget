# Расписание ТУСУР

Приложение для Android, которое показывает расписание занятий выбранной группы ТУСУР и позволяет вывести его на главный экран телефона в виде виджета. Данные загружаются с [сайта расписания ТУСУР](https://timetable.tusur.ru/).

## Возможности

- Поиск и выбор учебной группы по номеру или названию факультета.
- Просмотр расписания по дням и переключение между днями свайпом.
- Виджет на главном экране с расписанием выбранной группы.
- Переключение дней прямо в виджете и изменение его размера.
- Настройка оформления виджета: фон, цвета обычных и текущих занятий, скругление углов.
- Отображение типов занятий по цвету и стилю границ карточек.
- Ручное и фоновое обновление расписания.
- Сохранение последнего загруженного расписания на телефоне — оно остаётся доступным без интернета.
- Проверка новых версий приложения и установка обновлений через системный установщик Android.

## Установка

**[Скачать последнюю версию для Android](https://github.com/ayriix/tusur-scheduler-widget/releases/latest/download/tusur-schedule.apk)**

Для установки нужен Android 6.0 или новее.

1. Скачайте APK-файл по ссылке выше.
2. Откройте загруженный файл на телефоне. Если Android запросит разрешение на установку из этого источника, разрешите его.
3. Нажмите «Установить».

При первом запуске выберите свою группу и загрузите расписание при подключении к интернету.

## Виджет

Чтобы добавить виджет, нажмите и удерживайте пустое место на главном экране телефона, откройте **«Виджеты»** и выберите **«Расписание ТУСУР»**. Размер и положение виджета можно изменить на рабочем столе. Настройки его оформления находятся в приложении в разделе **«Редактор виджета»**.

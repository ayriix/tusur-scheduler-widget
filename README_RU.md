# TUSUR Schedule 2.3.0

Android-приложение с домашним виджетом расписания ТУСУРа.

## Исправления 2.2
- Виджет больше не использует `ListView`, `RemoteViewsService` и коллекционные адаптеры. Занятия передаются в `RemoteViews` как обычные вложенные строки, чтобы исключить зависание загрузки коллекции в лаунчере.
- Удалена сериализация Bitmap для каждой карточки занятия. Фоны — XML drawable resources, применяемые tint через RemoteViews. Это снижает размер RemoteViews payload и устраняет один из наиболее вероятных источников белых виджетов/вечного состояния загрузки на некоторых лаунчерах.
- Фон самого виджета тоже использует shape drawable с динамической окраской, а не передаваемый bitmap; радиус выбирается из shape ресурсов с шагом 2 dp.
- Каталог групп больше не загружается целиком при открытии экрана. Пока поле поиска пустое, показывается подсказка; поиск сначала использует локальный кэш, а каталог запрашивается из сети только при ненайденном запросе.
- Иконка карандаша уменьшена до визуального размера иконки обновления; круговые кнопки сохраняют одинаковые размеры.
- Добавлена системная страница настроек оптимизации батареи с fallback на сведения о приложении.
- Запрос закрепления использует официальный `requestPinAppWidget()` и callback PendingIntent. Приложение больше не показывает собственное модальное окно вместо системного подтверждения. Если лаунчер не поддерживает pinning, показываются инструкции ручного добавления.

## Сборка без Android Studio
Содержимое проекта загружается в корень GitHub-репозитория. GitHub Actions запускает `gradle assembleDebug` и публикует `app-debug.apk` в Artifacts. Workflow кеширует debug keystore, чтобы подпись APK оставалась постоянной между запусками.

## Исправления 2.3.0
- Для карточек добавлен тип занятия из полей iCalendar (описание, категории и комментарии): лекция, лабораторная работа, практика, семинар, консультация и экзамен. Если источник не передаёт тип, используется нейтральная граница.
- Цвет границы занятия фиксирован и не зависит от настроек цвета фона/темы виджета. В редакторе предпросмотр показывает типовые границы.
- Увеличены внутренние интервалы блока «Работа в фоне».
- Обновлён механизм вывода списка занятий в виджете: вместо коллекционного адаптера формируется статическое дерево RemoteViews, что устраняет наиболее вероятную причину белого плейсхолдера с бесконечной загрузкой на отдельных лаунчерах.
- Версия приложения: versionCode 6, versionName 2.3.0.

## Ограничения
- Фоновое обновление зависит от WorkManager, доступности сети и настроек энергосбережения производителя.
- `requestPinAppWidget()` зависит от поддержки текущего лаунчера. Android не предоставляет приложению универсальную команду для принудительного открытия меню «Виджеты» любого производителя. Если быстрый запрос не поддерживается, пользователь добавляет виджет через рабочий стол.
- Визуальное отображение следует дополнительно проверить на OriginOS и нескольких сторонних лаунчерах. Для подтверждения причины белого экрана нужен logcat с устройства, но переход на статическое дерево RemoteViews убирает зависимость от RemoteViewsService/адаптера.

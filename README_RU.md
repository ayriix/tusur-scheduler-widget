# TUSUR Schedule 2.0

Android-приложение и домашний виджет расписания ТУСУРа. Проект рассчитан на установку на телефоны Android, включая iQOO с Funtouch OS. Android Studio для сборки не требуется: APK собирается GitHub Actions.

## Что изменено в версии 2.0

### Приложение
- Переработан главный экран в спокойной Material 3 стилистике: ясная типографическая иерархия, нейтральная тёплая поверхность, графитовый текст и терракотовый акцент.
- Сохранены две основные команды: обновление расписания и открытие официальной страницы выбранной группы в браузере.
- Добавлен каталог групп. При открытии экрана выбора приложение получает список факультетов с главной страницы ТУСУРа, затем собирает ссылки на группы с факультетских страниц. Поддерживаются группы, опубликованные на сайте, включая группы магистратуры и аспирантуры, если они присутствуют в каталоге расписания.
- Добавлен поиск по номеру группы и названию факультета.
- Добавлен отдельный экран внешнего вида виджета.

### Виджет
- Группа отображается сверху слева; название университета и повторная подпись «Расписание группы…» убраны.
- Для каждого занятия формируется отдельная строка: время, название предмета и аудитория.
- Список — настоящий вертикально прокручиваемый `ListView` внутри Android App Widget, а не единый текстовый блок.
- Дата выбранного дня отображается вверху.
- Нижняя панель закреплена вне прокручиваемого списка: слева дата/время последней синхронизации, справа стрелки предыдущего и следующего дня.
- Текущая пара выделяется отдельным цветом.
- По умолчанию используется мягкое закругление. Радиус можно менять в настройках оформления.
- Можно отдельно менять фон виджета, цвет обычных занятий и цвет текущего занятия.
- При изменении размера виджета список получает больше или меньше доступной области; нижняя панель остаётся на месте.

## Источник расписания и выбор группы

Каталог групп собирается с публичных страниц `https://timetable.tusur.ru/` и факультетских разделов. Для выбранной группы используется её iCal-адрес: к URL страницы группы добавляется `.ics`. Пример для группы 576-1:

`https://timetable.tusur.ru/faculties/fvs/groups/576-1.ics`

Расписание сохраняется в локальном кеше. При отсутствии соединения виджет продолжает показывать последнее успешно загруженное расписание. Каталог групп и свежие изменения расписания требуют доступа к сайту хотя бы во время загрузки.

## Сборка APK через GitHub

1. Распаковать архив проекта.
2. Загрузить **содержимое** папки `TUSUR-Schedule` в корень GitHub-репозитория, не создавая дополнительную вложенную папку.
3. Убедиться, что в репозитории есть `.github/workflows/main.yml`.
4. Открыть **Actions → Build Android APK → Run workflow**.
5. После успешной сборки открыть запуск и скачать `TUSUR-Schedule-debug` из раздела **Artifacts**.
6. Распаковать ZIP с артефактом и установить `app-debug.apk`.

## Добавление и настройка виджета

На рабочем столе телефона: зажать свободное место → **Виджеты** → **TUSUR Schedule** → перетащить на экран. Изменить ширину/высоту можно перетаскиванием границ виджета. Вертикально прокручивается только список занятий, дата обновления и стрелки остаются в нижней панели.

В приложении доступны:
- **Изменить** в карточке группы — открыть каталог групп;
- **Обновить расписание** — запустить синхронизацию;
- **Открыть расписание в браузере** — открыть официальную страницу выбранной группы;
- **Настроить виджет** — изменить закругление, фон и цвета карточек.

## Ограничения

- На первом запуске каталог и расписание нужно получить через сеть. После синхронизации расписание хранится локально.
- Фоновая синхронизация зависит от ограничений Android и энергосбережения Funtouch OS.
- Android Launcher и оболочки производителей сами могут применять системную маску углов виджета. Настройка радиуса меняет внутреннюю подложку приложения, но отдельная оболочка может дополнительно обрезать внешний край.
- Список групп зависит от открытых страниц расписания, доступных на официальном сайте ТУСУРа. Если сайт изменит URL или разметку, парсер каталога потребуется обновить.

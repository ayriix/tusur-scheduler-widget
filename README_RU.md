# TUSUR Schedule 2.1

Android-приложение с виджетом расписания ТУСУРа. Сборка выполняется через GitHub Actions — Android Studio на компьютере не требуется.

## Изменения версии 2.1

- Приложение запускается в тёмной теме.
- Контент всех экранов учитывает системные отступы status bar / navigation bar, чтобы заголовки не попадали под шторку.
- Главный экран использует один заголовок «Расписание занятий».
- Выбор группы показывает полноценные строки на всю ширину; поиск работает по названию группы и факультету.
- Внешний вид виджета редактируется в отдельном экране: радиус, цвет фона виджета, цвет обычных занятий и цвет текущего занятия. Для цвета доступны HSV-ползунки и ввод HEX `#RRGGBB`.
- При первом запуске версии 2.1 настройки оформления мигрируют на тёмные значения по умолчанию один раз; после этого выбранные пользователем цвета сохраняются.
- На Android 12+ список виджета передаётся через `RemoteViews.RemoteCollectionItems`, без отдельного удалённого сервиса. На более старых версиях оставлен `RemoteViewsService`.
- Нижняя строка виджета закреплена отдельно от списка: стрелки расположены слева и справа, время последнего обновления — по центру.
- Аудитории форматируются: `ф 327` → `ФЭТ 327 кабинет`, `гк 428` → `ГК 428 кабинет`.
- Добавлена иконка приложения — белая T на синем фоне.
- Кнопка «Добавить на экран» вызывает системный запрос закрепления виджета, когда его поддерживает текущий launcher.

## Сборка APK через GitHub

1. Распакуйте архив.
2. Откройте папку `TUSUR-Schedule` внутри архива.
3. Загрузите **содержимое** этой папки в корень существующего репозитория GitHub. Замените совпадающие файлы и сохраните скрытую папку `.github`.
4. Сделайте `Commit changes` в ветку `main`.
5. Вкладка Actions запустит `Build Android APK` автоматически. Либо запустите workflow вручную.
6. В успешном запуске скачайте Artifact `TUSUR-Schedule-debug`, распакуйте его и установите `app-debug.apk`.

Workflow сохраняет debug keystore между запусками. Поэтому после первой установки сборки 2.1 последующие сборки должны обновляться поверх неё без удаления приложения. При первом переходе с предыдущей версии Android всё ещё может потребовать удалить старую debug-сборку из-за старой подписи.

## Виджеты и совместимость

- При открытии приложения повторно строятся уже установленные виджеты, поэтому после обновления APK существующий экземпляр не должен оставаться на старой пустой разметке.
- Android 12 (API 31) и новее: список занятий передаётся непосредственно в `RemoteViews` как `RemoteCollectionItems`.
- Android 6–11: используется `RemoteViewsService`.
- На Android 8.0+ приложение может запросить добавление виджета через `requestPinAppWidget()`, но окончательное решение принимает текущий launcher. Если launcher не поддерживает запрос, приложение покажет стандартную инструкцию ручного добавления. Универсального системного окна, которое можно принудительно открыть во всех оболочках Android, нет.
- Внешний радиус виджета отрисовывается растровым фоном. Домашний экран конкретного производителя может дополнительно применять собственное скругление или маску.
- Первое получение расписания требует доступа к календарю ТУСУРа. После успешной загрузки расписание хранится локально.

## Проверки перед публикацией

После облачной сборки протестируйте на реальном устройстве:

1. Список занятий внутри виджета, прокрутку и обновление после переключения дня.
2. Видимость строк каталога группы и работу поиска.
3. Отступы системных панелей на главном экране, выборе группы и редакторе виджета.
4. Контраст текста при выборе тёмных и светлых цветов карточек.
5. Кнопку добавления виджета на текущем launcher.

# TUSUR Schedule — виджет расписания для группы 576-1

Нативное Android-приложение с изменяемым виджетом. Источник расписания — официальный iCal-файл ТУСУРа:

https://timetable.tusur.ru/faculties/fvs/groups/576-1.ics

## Что реализовано
- Группа 576-1 (Факультет вычислительных систем).
- Изменяемый по ширине и высоте виджет Android.
- Текущая/следующая пара и аудитория.
- Список занятий на сегодня.
- Локальный кэш: ранее загруженное расписание остаётся доступным офлайн.
- Ручное обновление нажатием на виджет или в приложении.
- Фоновое обновление по сети примерно раз в 6 часов.
- Время расписания интерпретируется в часовом поясе Томска (Asia/Tomsk).

## Как получить APK без Android Studio
1. Создайте репозиторий на GitHub.
2. Распакуйте архив и загрузите ВСЕ файлы и папки проекта в корень репозитория.
3. Откройте вкладку **Actions** и разрешите запуск GitHub Actions, если GitHub попросит.
4. Запустите workflow **Build Android APK** кнопкой **Run workflow**.
5. Дождитесь зелёной галочки. Откройте завершённый запуск, внизу найдите **Artifacts** и скачайте `TUSUR-Schedule-debug`.
6. Распакуйте архив на телефоне, установите `app-debug.apk`. При запросе разрешите установку из этого источника.

## Добавление виджета
На iQOO: зажмите пустое место рабочего стола → Виджеты → TUSUR Schedule → перетащите на экран. Чтобы изменить размер, зажмите установленный виджет и потяните за границы.

## Ограничения первой версии
- Для первого получения расписания нужен доступ к `timetable.tusur.ru`. После успешной загрузки данные остаются в кэше.
- Фоновая синхронизация зависит от ограничений Android/iQOO по энергосбережению и доступности сети.
- Android launcher сам определяет минимальный размер и число строк, поэтому отображение может немного различаться в зависимости от лаунчера.
- Если ТУСУР изменит формат iCal, потребуется обновить парсер.
